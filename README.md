# Günün Mesajı - React Native SQLite Uygulaması

Bu proje, Veri Tabanı Yönetim Sistemleri dersi ödevi kapsamında geliştirilmiş, React Native ve yerel SQLite veritabanı kullanılarak hazırlanan tek ekranlı bir not alma uygulamasıdır.

##  Özellikler (CRUD İşlemleri)
Uygulama, yerel veritabanı (offline) üzerinde tam kapsamlı veri yönetimi yapabilmektedir:
* **Create (Ekleme):** Kullanıcılar günlük mesajlarını veya notlarını sisteme ekleyebilir.
* **Read (Okuma):** Eklenen notlar veritabanından çekilerek ana ekranda liste halinde görüntülenir.
* **Update (Güncelleme):** Mevcut bir not "Düzenle" butonuna basılarak seçilebilir ve içeriği güncellenebilir.
* **Delete (Silme):** İstenilmeyen notlar "Sil" butonu ile veritabanından kalıcı olarak temizlenebilir.
